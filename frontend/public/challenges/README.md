# WELCOME TO LOS SANTOS · FLAG THEFT AUTO

You're a 2–3-person crew in a fictional cyber-heist universe. Your task is to recover a unique `FTA{...}` code from each mission's evidence. No challenge requires access to any real service.

**How to play:** log in to the CTFd scoreboard with the credentials your organizers issued to your crew (public registration is closed); select a mission; download exactly that mission's attached evidence files; investigate locally; submit the complete recovered flag, with braces and case preserved. One correct submission per challenge per team earns the full point value. The organizer can provide the whole participant evidence package for offline backup.

The missions are grouped in `EASY/` (The Street Job, 12 missions, 50 points each), `MEDIUM/` (The Big Heist, 8 missions, 100 points each) and `HARD/` (The Final Getaway, 5 missions, 160 points each). Total possible: 2,200 points. You may solve missions in any order, except the sequential Nightshift trilogy (M06 → M07 → M08).

Recommended tools: Python 3.9+, a text editor, Terminal/PowerShell or WSL2, `file`, `unzip`, `xxd`, Python Pillow, Wireshark, `strings`, `objdump`, `readelf`. All are free; missions have offline alternatives using Python. Some reverse-engineering binaries are built for Linux x86-64, so Windows crews should use WSL2 Ubuntu or a provided Linux machine.

Three progressive hints per challenge are available in CTFd; each unlocked hint deducts points from your crew's score (10 / 20 / 30 for Easy / Medium / Hard). Hints are optional; creativity and collaboration inside your crew are encouraged. Submit only the flag, not working or screenshots.

**Important:** the fictional locations are just story. No scanning or probing the college network, real websites, team accounts, or other participants is permitted. See `RULES.md`.
